# MustEat

Year 3019. Going outside is illegal. Everyone must eat.

An idle food-delivery game that is also a pyramid scheme. Run deliveries, buy gear, open a shop, recruit runners with a link, take a cut of everything they earn.

**Play:** https://lukexyz.github.io/musteat/

Single HTML file, no build, saves in your browser. `ledger.html` shows who is paying whom. Technical notes in `NOTES.md`.

cd test && npm install && node smoke.js
